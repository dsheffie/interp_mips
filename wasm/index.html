The canvas is the G364 framebuffer: the kernel boots on it and hands off to an interactive BusyBox shell on tty1 — click the canvas and type (reboot -f restarts). The serial console above (ttyS0) is output-only — it shows the kernel log plus the init banner and its awk/md5/printf self-tests up to JAZZ-MINI-DONE. A self-contained clean-room stack — our own ARC firmware shim plus a GPL MIPS Linux kernel with an embedded BusyBox rootfs. Nothing is uploaded or sent anywhere.

Run Windows NT 4.0 (bring your own ROM + disk)

NT 4.0 (MIPS) ran on this exact machine. It's not bundled — it's Microsoft's proprietary code — but if you own a copy you can supply the three files below. The disk is a qcow2 image (qemu-img convert -O qcow2 nt4.raw nt4.qcow2 if yours is raw); it's parsed in-browser, only its allocated clusters are kept in memory (~230 MB), and writes stay local — your file is never modified. Nothing is uploaded or sent anywhere.

Built with interp_mips (jazz branch) · r9999 core · Berkeley SoftFloat · SDL2→canvas via Emscripten.
