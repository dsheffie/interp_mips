Windows NT–era MIPS, in your browser

The r9999 MIPS interpreter (interp_mips) built to WebAssembly, emulating a Microsoft Jazz / MIPS Magnum 4000 — booting a clean-room Linux to the G364 framebuffer.

Click Boot Linux, then click the screen to capture keyboard & mouse (Ctrl+Alt or switch tabs to release). This is a self-contained clean-room stack — our own ARC firmware shim plus a GPL MIPS Linux kernel with an embedded BusyBox rootfs. Nothing is uploaded or sent anywhere.

Run Windows NT 4.0 (bring your own ROM + disk)

NT 4.0 (MIPS) ran on this exact machine. It's not bundled — it's Microsoft's proprietary code — but if you own a copy you can supply NTPROM.RAW, a raw disk image, and an 8 KiB NVRAM file. Browser NT support is still in progress (the disk-streaming + high-memory mapping aren't wired yet); these pickers are a placeholder.

Built with interp_mips (jazz branch) · r9999 core · Berkeley SoftFloat · SDL2→canvas via Emscripten.
